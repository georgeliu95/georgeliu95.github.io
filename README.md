# George · Reports

报告站点：https://georgeliu95.github.io/

GitHub Pages 从 `main` 分支根目录发布，首页是 `index.html`。

## 添加报告

1. 将可公开的 PDF 或 HTML 报告及其资源放入 `reports/<report-name>/`。
2. 在 `index.html` 的“报告目录”中添加报告名称、简介和相对链接。
3. 将更新推送到 `main`，GitHub Pages 会自动部署。

例如 PDF 地址可以是 `reports/my-report/report.pdf`，HTML 地址可以是
`reports/my-report/index.html`。HTML 使用的图片、样式等资源也需要一起上传，
并使用相对路径。

此仓库及发布的站点公开可见，仅上传适合公开的内容。
